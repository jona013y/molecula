# Molecula

Molecula is an independent Rust desktop editor for chemical structures and reaction diagrams. It includes a molecular graph editor, selection and transforms, zoom/pan, reaction roles and stoichiometry, a guided naming subset for supported chains and simple carbocycles with saturated branched alkyl substituents, halo and neutral primary-amino substituents, cycloalkanols/cycloalkanones and their single-alkene cycloenol/cycloenone variants and bounded cyclic diene/ketone naming, terminal nitriles (including a C=C bond in their parent chain), and straight-chain alkyl alkanoate esters; mixed nitrile/carbonyl/alcohol cases and unsupported amides and uncovered heteroatom groups are refused, local formula/mass and topological-graph analysis, composable atom-query predicates, a bounded SMARTS importer/exporter, typed isotope editing (`@13`, `@0` to clear), atom aliases (`label:Ph`, `label:-` to clear), undoable radical-state editing, implicit-hydrogen override controls, editable per-atom valence overrides, selected-bond order/style editing and manual E/Z labels, searchable built-in and persistent user templates with a translucent placement preview and 60° rotation using `R`, including formula-checked naphthalene, indole, quinoline, anthracene, phenanthrene, decalin and norbornane graphs plus all 20 standard proteinogenic amino-acid templates with stereochemistry left unspecified, saved Danish/English, theme and implicit-hydrogen display preferences, multi-document tabs, crash recovery, MOL V2000/V3000, SDF, RXN, SVG, PNG and PDF support, manual unique reaction atom mapping (`M+`/`M=`) plus optional RDKit CIP R/S label assignment with undo, a rotatable 3D viewer with wireframe, sticks, ball-and-stick, spacefill and monochrome modes, and a searchable command palette (`Cmd/Ctrl+Shift+P`). PubChem Services include separate actions for a browser search and direct property lookup by exact structure through NCBI PUG REST. Direct lookup requires internet access and curl, sends the current representable structure only after the user selects that command, and shows record-linked data without changing the drawing. It is not a MarvinSketch clone or a complete cheminformatics package. See [STATUS.md](STATUS.md) for verified scope and limits.

Choose **Edit → Copy drawing as image** to put a 1920×1080 PNG of the current drawing on the system clipboard. The command uses the native clipboard route for macOS, Windows or Linux and reports if that route is unavailable.

To change an existing bond directly, select it and use **Make double (=)** in the bond inspector, or choose the desired bond tool and click its midpoint; for example, press `2` and click a single bond to make it double. Clicking an atom still starts the normal bond-drawing gesture. The edit is selected for inspection and can be undone.

The editor and visual assets are original Molecula work; no MarvinSketch source code, icons, or screenshots are included. Canvas zoom is saved as the user's default and reused for new documents and after restarting. Local analysis reports formula, supported mass values, valence warnings and graph topology (connected components, cycle rank and average degree); **Calculations → Local topological descriptors** additionally calculates the Wiener index, graph diameter, Zagreb indices and Randić connectivity from the connected heavy-atom graph. These are graph descriptors, not physical-property predictions; explicit hydrogens are excluded and query/nonstandard structures are refused. Methods and boundaries are stated in the report. Average masses use [CIAAW standard atomic weights](https://ciaaw.org/atomic-weights.htm) (2024 table; midpoint for interval values); isotopically labelled atoms use listed isotope masses. Exact ionic masses account for electron gain/loss. Elements without a standard weight or a listed isotope mass are reported as unavailable, not guessed. Choose **Calculations → Reaction analysis** to inspect each step, including conditions written above and below its arrow, a component-by-component table of assigned/inferred roles, coefficients, formulas and charges, element and isotope balance, and mapped bond changes. **Auto-balance reaction** solves a uniquely determined step while conserving elements, labelled-isotope counts and formal charge; **Auto-balance all reaction steps** solves every step before changing coefficients, refuses ambiguous or unresolved steps without partial edits, and is undoable. Third-party components and their licenses are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). This is a practical source and dependency review, not legal advice or a trademark clearance opinion.

## Chemistry A acid/base calculations

Open **Calculations → Chemistry A calculations**. In addition to buffer pH from pKa and concentrations, pKa from measured buffer data, weak monoprotic acid/base pH, strong acid/base mixtures, polyprotic species fractions, Bjerrum diagrams and polyprotic titration pH/curves, the panel includes amount from mass, mass from amount, concentration, dilution, and pH/pOH conversions. Each basic calculation shows its equation, substituted values, units, and result. The Bjerrum and titration charts can copy plotted values as CSV. Danish and English labels, reports, and example inputs are available through Settings.

Enter values in the order shown in the dialog, separated by semicolons. Decimal commas or points work; separate successive pKa values with `|`. For example, a buffer input `4,76; 0,10; 0,20` gives pH about 5.06. The pKa used in an exercise must come from your class data or a cited table. Molecula does not estimate pKa from the drawn structure or invent database values.

These calculations use ideal aqueous concentrations, 25 °C and `Kw = 1.0×10⁻¹⁴`; they do not correct for activity, ionic strength or other non-ideal effects. Results are intended for Chemistry A learning and should not be treated as experimentally validated predictions. See [STATUS.md](STATUS.md) for exact scope.

## Learning center and local chemistry helper

Open **Help → Learning center** for searchable Danish/English guides to pH, buffers, titrations, amount of substance, reactions, naming and the editor. **Help → Ask local chemistry helper** answers supported questions using reviewed, bundled material. It works offline and sends no structure or question to a service. It is a bounded keyword and intent matcher, not a generative AI model; questions outside its reviewed topics receive a clear fallback instead of an invented answer. Structure-based pKa prediction is not provided.

**Help → Chemistry A practice** offers four interactive numerical exercises with progressive hints and answer checking against the same local calculation routines. Correctly solved exercise progress is stored locally beside the app settings. These guides and exercises support learning; they are not a substitute for a teacher's chosen conventions or source data.

## Download and first-run security warnings

Download only from the [official releases](https://github.com/jona013y/molecula/releases). Unsigned builds may show publisher-verification warnings because they are not notarized by Apple or signed with a Windows publisher certificate. That warning alone does not establish whether a file is safe; verify that it came from this repository and compare its SHA-256 if a checksum is published.

- **Mac:** Open Molecula once. If the warning appears, click **Done**. Go to **System Settings → Privacy & Security**, scroll down, click **Open Anyway** next to Molecula, then confirm **Open**. Apple describes this one-app exception in its [Gatekeeper instructions](https://support.apple.com/en-us/102445).
- **Windows:** On **Windows protected your PC**, click **More info → Run anyway**. Microsoft explains why new or unsigned downloads can show this [SmartScreen warning](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation).

These steps apply only to the publisher-verification warning. If macOS says the app will damage your Mac, or Windows Defender reports a specific threat, cancel and do not override that alert.

## Build and run

Install Rust, then run:

```sh
cargo test --locked --offline
cargo run --release --locked --offline
```

The Windows installer script requires Inno Setup. The macOS package script creates an arm64 package on Apple Silicon; universal builds require both `aarch64-apple-darwin` and `x86_64-apple-darwin` Rust targets. macOS bundles are checked for their executable, `PkgInfo`, valid ICNS Dock icon, and CPU architecture before packaging.

For direct PubChem lookup, choose **Services → Fetch PubChem properties**; this sends the current structure only when the local SMILES writer can represent it, then asks the official NCBI PUG REST API for `same_stereo_isotope` identity matches and linked record values. The local writer currently refuses stereochemical annotations it cannot serialize, so those drawings are not sent. It requires internet access and the system `curl` program; it does not modify the drawing. **Services → Search PubChem in browser** only opens a search and retrieves no data. The parser and report formatting are tested locally; live lookup could not be verified in this environment because DNS resolution for PubChem is blocked.

The optional RDKit bridge requires a separate Python environment with RDKit installed. Choose **Calculations → Gasteiger partial charges** to calculate RDKit Gasteiger-Marsili partial charges asynchronously; the report shows atom values, implicit-hydrogen charge totals, elementary-charge units, 12 iterations, and a net-charge check against the formal charge. This is a modelled charge distribution, not a quantum calculation, and the drawing is unchanged. The same bridge descriptor report includes RDKit logP/TPSA, H-bond counts, ring and topology measures, Labute ASA and related properties, with method and unit labels. When the RDKit build includes `rdFreeSASA`, it also reports solvent-accessible surface area for a deterministic ETKDGv3 conformer minimized with MMFF94 or UFF; the report identifies the force field, Shrake-Rupley method, van der Waals radii, and 1.4 Å probe. SASA is conformer-dependent; the generated coordinates do not replace the document's structure. Candidate reports enumerate up to 100 tautomers or up to 64 unique isomers at unspecified stereo centers without changing the source document. The bridge also preserves imported tetrahedral and E/Z stereochemistry through the native document model and chemistry-engine SMILES export, applying explicit E/Z annotations even when 2D layout conflicts, and provides broader SMILES conversion as a fallback, 3D conformer generation, aromatize/Kekulé operations, stereochemistry reporting, and an explicit action to apply returned CIP R/S labels as undoable atom annotations. RDKit-backed import is wired for MOL2, PDB and InChI; export is wired for PDB, InChI and InChIKey. Local CML import/export supports one molecule with atoms, bonds, charges, isotopes, implicit hydrogen overrides, 2D/3D coordinates, molecule name and simple metadata. CML annotations outside this subset are refused on import or listed in the export loss warning. These RDKit conversions are unavailable until RDKit is installed. PDB export also needs 3D coordinates, and MOL2 relies on compatible atom typing. They do not provide every property or name in the full specification. See `STATUS.md` for exact coverage and limitations.

For a local substructure search, draw the query fragment and target molecule(s) as separate disconnected components on the same canvas, select the complete connected query molecule, then choose **Structure → Find substructure matches**. Matching target atoms are selected and listed. Supported atom and bond predicates include element lists and exclusions, any atom, heteroatom, aromaticity, H counts, degree/connectivity, valence, unsaturation, exact substitution count (`.sN`) and substitution count as drawn (`.s*`), bond order alternatives, ring-only and chain-only bond topology (set on a selected bond in the inspector), ring-bond count, exact smallest ring size, ring count (`.R0`, `.R1`, …), exact stored R/S atom labels, and exact stored E/Z/cis/trans double-bond labels. Use **Edit → Copy as SMARTS** or **Cmd/Ctrl+Shift+K** to export the supported subset; Save As `.smarts` writes the query text after a loss warning, and opening `.smarts` parses the supported subset locally. The bounded parser supports ordinary atoms, bracket atom selectors, supported predicates, charges, isotope labels, atom maps, bond-order alternatives, branches, ring closures and disconnected components; imported coordinates are laid out from the molecular graph. Recursive SMARTS, stereo groups, wedge/hash stereo and unsupported terms are rejected. The bounded SMARTS reader/writer was not validated by RDKit; the optional RDKit conversion and descriptor workers were smoke-tested separately. RDKit is not installed in the default interpreter. MOL/SDF V3000 round trips preserve the supported atom selectors, bond query types 5–8 and ring/chain topology (`TOPO=1/2`). Ring count uses Molecula's deterministic minimum cycle basis; in graphs with tied cycle bases, another toolkit can report different ring memberships. Partial selection of a query molecule is refused. Neither the local matcher nor SMARTS import/export is a full SMARTS implementation.

## Files and document recovery

In **Insert → Templates**, selecting a built-in or saved user template displays a translucent preview that follows the pointer. Press `R` to rotate the preview by 60° before placement; press `Esc` to cancel. To attach the template, select exactly one existing atom before opening the library and press `A`; the preview aligns its nearest-to-center atom one bond length away and clicking creates a real single bond in the molecular graph. The attachment is undoable. Saved user templates can be placed repeatedly.

Use **Insert → Edit molecule data** to set a molecule name with `NAME=value`, save/update data fields with `KEY=value`, or remove fields with `-KEY`; edits are undoable and preserved in native documents and SDF. Use **File → New/Open/Save** to work with documents. In **Insert → Templates**, save a connected selected fragment under a custom name, then find, insert, rename or delete it in **My templates**; duplicate names are rejected, and renaming preserves the graph. The user library is stored as native editable graphs in the app settings directory. Native `.mols` v4 preserves Molecula document data (older v1–v3 documents remain readable). MOL/SDF import and export supports V2000 and the implemented V3000 atom/bond subset, including charge, isotope, atom maps, supported local stereobond data, unspecified/either atom parity, V2000 H-count overrides H0–H4, V3000 HCOUNT (H0–H5), exact SUBST/RBCNT and UNSAT atom-query fields, V3000 query bond types 5–8 and ring/chain topology `TOPO=1/2`, valence overrides, aromatic atom restoration and singlet/doublet/triplet radical records; RXN supports basic V2000-style reactant/product/agent components. V2000 valence overrides 0–14 and zero-valence are preserved; values above 14 need V3000. Exchange formats can omit editor graphics, stereochemical/query detail or stoichiometry; the save flow blocks the write and asks for confirmation when it detects loss, including SMILES layout and document annotations. `.smi` and `.smiles` files use a local bounded parser/writer for ordinary and aromatic atoms, charges, isotopes, bracket hydrogen counts, atom maps, branches, rings and disconnected fragments. Local SMILES import rejects stereochemical and query syntax it cannot preserve; optional RDKit is tried as a fallback. CML import/export uses a bounded local subset (one molecule, ordinary atoms and bonds, supported stereo and simple metadata); unsupported CML child annotations are refused, and export warns about unsupported graph or document data. MOL2, PDB and InChI imports, plus PDB, InChI and InChIKey exports, still require RDKit. A row of tabs appears below the toolbar. Unsaved tabs are marked with a dot. Dirty workspaces autosave every 20 seconds to the application-support/config directory in a separate `workspace.autosave` file and prompt for recovery at startup. **File → Recent files** lists recently used paths.

To install RDKit separately, use a Python environment supported by RDKit and set `MOLECULA_PYTHON` to that environment's interpreter. The app remains usable without it; dependent commands show an explicit error. MOL2 parsing depends on atom typing recognized by RDKit. PDB is best treated as a coordinate-oriented exchange format, not as a lossless archive for editor metadata.

## Repository layout

- `Molecula-source.zip` is the source archive used by the installer workflow. It omits the stale prebuilt app executable; package scripts compile the program and remap the build home path before shipping. Verify it with `shasum -a 256 -c Molecula-source.zip.sha256` on macOS/Linux or `certutil -hashfile Molecula-source.zip SHA256` on Windows.
- `Molecula-source.zip.sha256` is the published SHA-256 checksum for the archive.
- Installer workflows build from the checked-out source on the selected commit, so release builds use the exact published code.
- `THIRD_PARTY_NOTICES.md` documents dependency and bundled-font license notices.
- `src/` contains the Rust editor and chemistry model.
- `molecula.app/Contents/Resources/Molecula.icns` contains the original Molecula Dock icon.
- `scripts/verify_macos_bundle.sh` checks app bundle metadata and the icon during packaging.
- `SIGNING.md` describes optional publisher signing; no certificates or credentials belong in this repository.

### Optional automatic reaction atom mapping

To map a reaction locally, assign every reactant and product component the correct explicit role in the same reaction step, leave agents unselected, select all whole reactant/product components to include, then choose **Structure → Auto-map reaction**. The selected disconnected reaction sides are passed together to AtomMapper, which returns one atom correspondence across all selected components. Complete assigns maps to the full selected sides, Matching maps the shared core, and Changing maps atoms reported at changed atoms/bonds. The operation runs in the background and is undoable. Components are not auto-paired independently, so a shared core can span component boundaries when the chemistry engine finds it. Results show the engine's optimality status; completion is not proof of a globally optimal mapping.

This is an optional local integration. Install Python 3.11 or later, RDKit, and AtomMapper (`python -m pip install atommapper`), then set `MOLECULA_PYTHON` to that Python interpreter. AtomMapper also installs NetworkX and SciPy. The desktop app remains usable without these packages; automatic mapping reports the missing dependency and keeps the drawing unchanged. AtomMapper is MIT-licensed; it is not bundled in the application. See [AtomMapper's package page](https://pypi.org/project/atommapper/) and [source](https://github.com/craabreu/atommapper) for supported platforms, licensing and algorithm limitations.
