# Molecula feature status

This is an independent, evolving Rust chemical editor. It is not MarvinSketch and does not claim feature parity. “Verified” means covered by automated tests or a checked build in this workspace; a full visual/chemical validation campaign has not been completed for every workflow.

| Area | Status | Working now | Still missing or limited |

| Document workflow (A) | Implemented in core | Multi-tab documents; per-tab undo/redo; close/save/discard/cancel flow; quit protection; separate autosave recovery choice; recent files; persisted Danish/English and theme settings. | User profiles, saved zoom, print/page setup, crash-recovery stress testing and GUI accessibility review. |

## Local verification

The automated suite covers graph edits, chemistry summaries and topology (including cycle rank), CIAAW-based molar-mass entries, explicit isotope masses and ion electron-mass correction, formula-correct aromatic heterocycle templates (pyrrole, furan, thiophene and imidazole), V2000 implicit-hydrogen and valence override export/import, V3000 `VAL`, `HCOUNT`, `SUBST`, `UNSAT`, `RBCNT`, bond query types 5–8 and `TOPO=1`, native v1/v3 compatibility and v4 valence persistence, valence-driven implicit-H estimates, selected-bond order/style and manual E/Z edits with undo/redo, typed and composable atom-query parsing with invalid/conflicting predicate refusal, substructure matching across separate components, element/H/substitution predicate evaluation (including isotope-labelled hydrogen and `.s*`), symmetry de-duplication, aromatic-bond inference, exact minimum-ring and ring-bond queries, ring-topology bond matching, deterministic minimum-cycle-basis ring membership on fused rings, non-ring-atom matching, partial-query selection refusal, disconnected-query refusal, editor-command highlighting of actual matches, automatic reaction balancing including formal-charge conservation and ambiguity refusal, selection/move, settings, reaction-role analysis, native and workspace formats, MOL/SDF, RXN and V3000 round trips (including local stereo parity, unspecified/either parity, bond stereo direction, aromatic atom restoration, atom maps and V2000/V3000 radical records), MOL/SDF loss-warning precision, PNG decoding, PDF signature/content, teaching exercises, carboxylic-acid naming, non-truncating report wrapping, and optional RDKit job launch/failure handling. Latest verification: 105 unit tests pass; final `cargo fmt --check`, `cargo clippy --locked --offline --all-targets -- -D warnings`, and `cargo build --release --locked --offline` are pending. This does not replace hands-on GUI checking, execution with RDKit installed, or validation by a chemistry expert.

RDKit integration requires a separate supported Python environment with the `rdkit` package and optional `MOLECULA_PYTHON` pointing to its interpreter. The app remains usable without RDKit; the unavailable operations report that dependency rather than fabricating results. MOL2 parsing in RDKit expects compatible atom typing. PDB import/export is coordinate-oriented and is not a complete preservation format for chemical annotations. The optional conversion operations must be verified against installed RDKit before relying on them for research data.

## Remaining specification coverage

The original requested scope includes many features that are still unimplemented: comprehensive stereochemical representation, Markush/search constraints, all listed formats, print/page composition, bitmap/PDF output, arbitrary 3D manipulation, full computational chemistry, broad nomenclature, biomolecular sequence handling, direct web-service integrations, and customizable shortcut profiles. Those features must not be advertised as present until implemented and verified.
