# Molecula feature status

This is an independent, evolving Rust chemical editor. It is not MarvinSketch and does not claim feature parity. “Verified” means covered by automated tests or a checked build in this workspace; a full visual/chemical validation campaign has not been completed for every workflow.

## Local verification

Chemistry A calculation coverage includes reference-value checks for strong acid/base neutralization, buffer pH and inverse experimental pKa, weak-acid/base equilibria with water autoionization, polyprotic distribution fractions, half-equivalence/equivalence behavior, finite titration and Bjerrum curves, invalid inputs, Danish reporting, chart data and CSV-ready series. The 233-test application suite covers calculation logic, titration/speciation chart data, yield calculations, significant-figure formatting and persistence, and exercise grading; it does not verify every rendered GUI pixel or chemistry curriculum exercise.

The automated suite covers graph edits, chemistry summaries and topology (including cycle rank), CIAAW-based molar-mass entries, explicit isotope masses and ion electron-mass correction, formula-correct aromatic heterocycle templates, file-format round trips, reaction balancing and teaching exercises. Chemistry A calculations now include significant-figure formatting and persistence, balanced-coefficient limiting-reactant and theoretical/percent-yield calculations, additional answer-checked exercises, acid/base equilibrium and pKa functions, polyprotic speciation, Bjerrum diagrams, and charge-balance titration curves. Local checks currently pass 233 tests, including new precision, yield, input-validation and exercise-grading checks. The repository still requires GitHub release builds for the final packaged artifacts; no publisher-signing certificates are configured, so platform warnings remain expected. These checks do not replace broader manual GUI use or review by a chemistry expert.

RDKit integration requires a separate supported Python environment with the `rdkit` package and optional `MOLECULA_PYTHON` pointing to its interpreter. The app remains usable without RDKit; the unavailable operations report that dependency rather than fabricating results. MOL2 parsing in RDKit expects compatible atom typing. PDB import/export is coordinate-oriented and is not a complete preservation format for chemical annotations. The listed worker paths passed limited smoke checks against RDKit 2026.09.2, but each input still needs validation before research use; this does not replace broader GUI and chemistry-expert review.

## Remaining specification coverage

The original requested scope includes many features that are still unimplemented: comprehensive stereochemical representation, Markush/search constraints, all listed formats, print/page composition, cross-OS clipboard integration QA, arbitrary 3D manipulation, full computational chemistry, broad nomenclature, biomolecular sequence handling, direct web-service integrations, and customizable shortcut profiles. Those features must not be advertised as present until implemented and verified.
